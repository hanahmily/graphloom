# Changelog

All notable changes to GraphLoom are recorded here, in the style of
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow
[semantic versioning](https://semver.org/); before 1.0, a minor release may
break CLI flags and configuration (docs/design-release.md §3).

## [0.1.0] - 2026-10-27

First installable release of GraphLoom: a durable controller that runs
executable TypeScript graph plugins, with coding agents doing the work and a
supervisor recovering exceptional failures. It installs from a signed GitHub
Release, runs on its bundled Node, and ships the issue-fix graph.

### Added

- **Install and upgrade.** `install.sh` installs a signed, checksummed release
  into `~/.graphloom/versions/<v>` with a `graphloom` shim. `graphloom upgrade`,
  `graphloom self list|use|rollback|prune|uninstall`, and daily automatic
  updates (`autoUpdate: auto|notify|off` in runner.json,
  `GRAPHLOOM_DISABLE_AUTOUPDATE=1`). Before 1.0, automatic updates install
  patch releases only and announce minors.
- **Doctor and setup.** `graphloom doctor [--task <task.yaml>]` finds Claude
  Code, Codex, Pi credentials, `gh`, git, flock and bwrap, reports viable
  setups, and prints a `fix:` command for every problem. `graphloom setup`
  (guided, or `--yes`) writes runner.json and supervisor.json without secrets;
  the first interactive `run` starts it automatically.
- **Runs belong to the version that started them.** `resume`, `stop`, `wait`,
  `inspect`, `stats` and similar commands dispatch to the owning version;
  `resume --upgrade` moves a run forward through recorded state migrations.
- **Supervisor on three agents.** Pi with any provider Pi supports (OpenAI,
  Anthropic, Gemini, DeepSeek, MiniMax, Kimi, custom endpoints in Pi's
  models.json), Claude Code on its own login, or Codex on its own login.
  Plugins declare a preference; `run --supervisor` and
  `resume --supervisor` override it; `switch-model` works per harness;
  `stats` reports supervisor usage per harness.
- **Agent skills.** `graphloom skills list|install|update|remove` installs six
  skills for Claude Code and Codex: setup, issue, run, watch, triage and
  deliver. `graphloom wait --until progress [--since <cursor>]` reports
  meaningful run events for watching a run.
- **issue-fix graph 0.16.0** with repository profiles (banyandb,
  banyandb-ql, canopy, graphloom), context documents, bench gates, bundled
  open-code-review, per-profile agent timeouts and continuation of a
  timed-out agent session that made progress.
- **SDK** `graphloom-sdk-0.1.0.tgz` for plugin authors (sdkProtocol 1).

### Changed

- Licensed under Apache License 2.0.
- The supervisor and the coding-agent executor share one agent harness
  library; the executor carries its own vendored copy so its digest pin
  covers it.

### Removed

- The banyandb-fix example graph; use issue-fix with the banyandb profile.

### Upgrade notes

- **State format:** 1. This is the first release; there are no migrations.
  Runs started from a source checkout are not owned by an installed version
  and keep running where they are.
- **Configuration:** first release; runner.json and supervisor.json are
  written by `graphloom setup`. supervisor.json accepts both the flat Pi form
  and the per-harness form (`harnesses`, `select`, `pi`, `claude`, `codex`).
- **SDK protocol:** 1.
- **Node:** 24.22.1 (bundled).
- **Digests:** first release; every executor and plugin digest is new. Runs
  started from a source checkout before this release need
  `resume --update-executors` (and `--update-plugin` for issue-fix) to move
  onto these builds.

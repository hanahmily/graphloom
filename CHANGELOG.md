# Changelog

All notable changes to GraphLoom are recorded here, in the style of
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow
[semantic versioning](https://semver.org/); before 1.0, a minor release may
break CLI flags and configuration (docs/design-release.md §3).

## [0.2.0] - 2026-11-10

The first public release of GraphLoom, an agent harness and loop for open-source
maintainers. It runs graphs, which are executable TypeScript plugins, under a controller
that owns durable state, budgets, receipts and evidence. A supervisor session
recovers runs that go wrong. Earlier 0.1.x builds were local and unsigned; this is
the first signed release, installable with `scripts/install.sh`.

### Added

- **Graphs.**
  - `issue-fix` turns an issue into a reviewed, checked change that is ready to deliver.
  - `pr-review` reviews a pull request head and posts one `COMMENT` review that starts
    with a verdict line. Round 1 is a neutral change report with questions and answers;
    round 2 runs three aspect reviewers, each with verified findings.
  - `hello` and `release` are examples.
- **CLI:** `graphloom run`, `resume`, `check`, `inspect`, `stats`, `wait`, `watch`,
  `doctor`, `setup`, `rehearse`, `task new`, `session list|open`, `skills`,
  `upgrade` and `self`.
- **Recovery supervisor:** one supervisor session per recovery episode. It runs on
  Claude Code, on Codex (your own login, under bwrap), or on Pi with any Pi provider.
- **Confined jobs:** jobs run under bwrap or Docker, with filesystem, credential and
  network scopes. Coding agents run as Claude Code, Codex or Pi sessions.
- **Agent skills** for Claude Code, Codex and opencode. They start runs, watch them,
  triage them and deliver their results.
- **Releases:**
  - a pinned, bundled Node (26.13.0);
  - deterministic packing;
  - SSH-signed `SHA256SUMS`, checked against `release/allowed_signers`;
  - automatic daily updates, which `GRAPHLOOM_DISABLE_AUTOUPDATE=1` turns off.

### Changed

- Since the local 0.1.4 build, a test in the `pr-review` static-tools suite shadows
  `go` with a failing decoy instead of stripping `PATH`. CI runs three test workers
  per package.

### Upgrade notes

- **State format:** 2, the same as 0.1.x. No migrations; runs started on 0.1.x resume
  as they are.
- **Configuration:** none. `runner.json` and `supervisor.json` keys are unchanged
  since 0.1.4.
- **SDK protocol:** 1. Plugins built against `@graphloom/sdk` 0.1.x load unchanged.
- **Node:** 26.13.0 (bundled).
- **Digests:** every executor and plugin digest changed, because the lockstep 0.2.0
  version moved their SDK dependency. The table under Components lists their
  versions.
  Runs started on 0.1.x stay on their pinned versions unless they are moved with
  `resume --upgrade`.
